# Pollucare AI Layouts

React components for Pollucare AI interface layouts.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Layouts

- **Layout1**: Smart Solutions hero section with service list

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Montserrat Font
